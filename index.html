Dicas para Aproveitar o Material

Para garantir um estudo eficaz, recomendamos a seguinte abordagem:

  • Organização: Os arquivos estão separados por unidades/módulos. Siga a ordem numérica.
  • Autonomia: Baixe os materiais para consulta offline ou marque os arquivos importantes com estrela no seu Drive.
  • Dúvidas: Anote suas dúvidas durante a leitura para discutirmos nos próximos encontros síncronos.
